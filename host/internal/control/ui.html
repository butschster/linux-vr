Settings

Settings can only be changed from this machine. Open http://localhost:9099 there.

The rate must match the display, not the headset — asking for more than the monitor produces breaks timestamps and freezes the picture on one frame. Quality is a constant-quantiser setting: 23 is a good start for text. Both take effect the next time a window opens.

Dictation

The server sends the audio, not the headset: the key stays on this machine, and the text has to end up here anyway. For a local model, run it as an HTTP service and point this at 127.0.0.1.
